# 雲風智能有限公司 (CloudWind AI Limited) 官网

## 项目概览

这是雲風智能有限公司的公司官网，基于 React + TypeScript + Vite 构建，面向企业客户展示 AI 解决方案、财务咨询服务、团队能力、客户案例和联系方式。

## 基本信息

- **类型**: 公司官网
- **技术栈**: React 18 + TypeScript + Vite + Tailwind CSS
- **语言**: 中文 / 英文
- **用途**: AI 咨询、企业服务与财务顾问业务展示

## 主要页面

- `/` - 中文官网
- `/en` - 英文官网

## 核心业务模块

1. **AI智能营销套件**: 网站/App、内容引擎、品牌故事和营销数据分析
2. **AI运营优化助手**: AI辅助开发、智能客服、流程自动化和效率提升
3. **AI智能体定制**: 客服、法务、财务分析和业务流程自动化
4. **AI战略决策引擎**: 私有知识库、决策支持模型和商业洞察
5. **财务咨询与融资顾问**: 财务模型、融资方案、估值规划和投资人材料

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发环境

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 代码检查

```bash
npm run lint
```

## 部署

项目可部署到 Cloudflare Pages。若 Cloudflare Pages 已绑定 GitHub 仓库主分支，推送新提交后会自动触发部署。
