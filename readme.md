# 雲風智能有限公司 (CloudWind AI Limited) - 商业计划书项目

## 项目概览

这是一个名为**雲風智能有限公司 (CloudWind AI Limited)** 的商业项目，是一个基于React + TypeScript + Vite构建的现代化商业计划书展示网站。

### 基本信息
- **类型**: 商业计划书/公司官网
- **技术栈**: React 18 + TypeScript + Vite + Tailwind CSS + Chart.js
- **语言**: 中文（繁体）
- **用途**: AI咨询公司的商业计划展示和投资路演

## 项目结构

### 主要页面
- `/` - 主页面（公司官网）
- `/bp` - 商业计划书详细页面

### 核心功能模块
1. **AI解决方案展示**: 智能营销、运营优化、战略决策、智能体
2. **财务预测**: 三年收入预测图表
3. **融资计划**: 分阶段融资方案
4. **团队介绍**: 创始团队展示
5. **市场分析**: 市场规模和痛点分析

## 技术栈详情

### 前端技术
- **框架**: React 18 + TypeScript
