# 雲風智能有限公司 (CloudWind AI Limited) 官網

## 項目概覽

這是雲風智能有限公司的公司官網，基於 React + TypeScript + Vite 構建，面向企業客戶展示 AI 解決方案、財務諮詢服務、團隊能力、客戶案例和聯絡方式。

## 基本資訊

- **類型**: 公司官網
- **技術棧**: React 18 + TypeScript + Vite + Tailwind CSS
- **語言**: 繁體中文 / 英文
- **用途**: AI 諮詢、企業服務與財務顧問業務展示

## 主要頁面

- `/` - 繁體中文官網
- `/en` - 英文官網

## 核心業務模組

1. **AI 智能營銷套件**: 網站/App、內容引擎、品牌故事和營銷數據分析
2. **AI 營運與智能體助手**: AI 輔助開發、智能客服、流程自動化和崗位助手定制
3. **AI 戰略決策引擎**: 私有知識庫、決策支持模型和商業洞察
4. **財務諮詢與融資顧問**: 財務模型、融資方案、估值規劃和投資人材料

## 快速開始

### 安裝依賴

```bash
npm install
```

### 開發環境

```bash
npm run dev
```

### 構建生產版本

```bash
npm run build
```

### 代碼檢查

```bash
npm run lint
```

## 部署

項目可部署到 Cloudflare Pages。若 Cloudflare Pages 已綁定 GitHub 倉庫主分支，推送新提交後會自動觸發部署。
